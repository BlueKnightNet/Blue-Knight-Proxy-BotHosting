ONE-TIME SETUP

Connect it to Telegram.

  1. 01
    Register your proxy

    Open @MTProxybot ↗, send /newproxy and follow its instructions.

  2. 02
    Choose your channel

    Use /myproxies → Set promotion and select your public channel.

  3. 03
    Paste the promotion tag

    Enter the tag above and enable sponsorship. The username here is a label; Telegram's bot controls the association.

Telegram may take about an hour to refresh a promotion. It may not appear for people already subscribed to the channel.

For the bot's secret prompt: use the bare key, without the ee prefix or hostname.

PHONE-FRIENDLY SETUP

Copy, paste, deploy

  1. 01
    Create a Cloudflare Worker

    On your phone, open Cloudflare → Workers & Pages. Create a Hello World Worker with the branded name above, then open Edit code.

  2. 02
    Paste the standalone code

    Tap Copy ready-to-deploy Worker here. It includes your panel URL and private token. Replace the entire example Worker with it, then deploy. No variables, PC or terminal are needed.

  3. 03
    Enable and share

    Paste the workers.dev URL here, leave Endpoint public IPv4 empty for automatic resolution, enable WEB proxy and save. Share the WEB link below.

Use your own Cloudflare account. The ready-to-deploy code contains a private token: do not publish it. No manual hosting variables or Wrangler commands are needed. Telegram clients must support WEB proxies.
